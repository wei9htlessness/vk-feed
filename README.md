# vk-feed
- Скрипт для ВК ленты (vk.ru/feed)  
- Работает через браузерное расширение Tampermonkey  
- Скрытие постов сообщества/пользователя по 1 кнопке  
- Фильтр постов по словам с автоматическим скрытием  
- Работает на десктопных и мобильных браузерах (не в приложении)  
---- 
#### **УСТАНОВКА:** Поставьте для браузера расширение Tampermonkey и разрешите ему работу со скриптами, если это необходимо. На этой странице найдите [Releases](https://github.com/wei9htlessness/vk-feed/releases) и кликните по .js файлу, расширение должно подтянуть скрипт и установить его. Если этого не произошло, то скачайте файл, откройте расширение и установите его самостоятельно через копировать вставить или перетаскивание файла в окно расширения. Обновите страницу ВК, на постах появится кнопка "Бан" и три точки с настройками
